What is built

  • Accounts and isolation: register, sign in, profile. Everyone sees only their own files.
  • Files, folders, trash (7-day retention), share links, search, batch download and previews.
  • Live events (SSE), storage usage and admin endpoints.
  • Signed online self-update with automatic rollback, tested end to end. The release pipeline has produced v0.3.1-rc.2.

One program holds everything

Cloud Home is a single program called cloud_home. The API and the web app are served from the same address, and the database and files live on the external drive. The web app is not built yet, so it is drawn dashed.

Diagram. The moving dots show requests and updates flowing; with Reduce Motion on, they are hidden and the diagram is still.

How an update safely reaches the box

Every version contains the backend and the web app. They are replaced together and roll back together. Three of the steps can refuse or undo a bad update.
