What we learned

Three things worth writing down.

Chinese is not shorter

Button labels in both Chinese scripts are often as long as English, so every component is checked with the longest copy.

Empty states are design

On first launch there is nothing yet, so that screen invites the first action.

Updates should be quiet

The UI and backend update together; you see “reconnecting”, never a broken page.
